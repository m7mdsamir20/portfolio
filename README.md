## Stack

React 19 · TypeScript · Vite · Tailwind CSS 4 · lucide-react

## Run locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev` (http://localhost:3000)
3. Production build: `npm run build`

## Where things live

- `src/components/` — one component per section (Hero, About, Skills, SelectedWork, Experience, MyProcess, Footer, CVModal)
- `public/illustrations/` — hero and about illustrations
- `public/projects/` — project screenshots
- `public/cv.pdf` — downloadable CV
